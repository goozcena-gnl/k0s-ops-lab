# k0s Ops Lab

Status: **PLANNED / WORK IN PROGRESS**

## Planned Objective

This repository is intended to track and document a planned k0s operations lab focused on learning, testing, and documenting Kubernetes operational practices in a small, self-managed environment.

## Planned Scope

The planned lab is expected to cover operational topics around k0s and Kubernetes, including:

- cluster bootstrap and lifecycle workflows;
- node management and day-2 operations;
- workload deployment and service exposure patterns;
- upgrades, recovery drills, and basic troubleshooting;
- observability, maintenance, and operational documentation.

## Current Repository Status

This repository is documentation-only at this stage.

- There is currently **no implementation** in this repository.
- There is currently **no runtime evidence** for the planned lab.
- There is currently **no CI validation** for the planned work.
- There is currently **no production claim** associated with this repository.
